# Cult of the Numbers
Source code for Cult of the Numbers
https://pr-danielanthony.itch.io/cult-of-the-numbers
Four players and one board of cards. Everyone picks a card each round! Each card is worth their face value, but if multiple players grab the same card, the points get split between them. A 10 card is great if you grab it alone, but worth a lot less if someone else had the same idea. Be the only one to snatch the Special Card to steal 5 points from the leader, or gain 5 points if you're already in the lead! The game ends when the cards run out, or a player(s) reaches 20 points. Highest score wins! Do you chase the high-value cards everyone else is eyeing, or sneak away with something smaller, or maybe grab that Special card while they fight over scraps?
